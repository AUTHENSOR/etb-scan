# etbscan

**This is an alias. The real package is [`etb-scan`](https://pypi.org/project/etb-scan/).**

```bash
pip install etb-scan
```

Installing `etbscan` installs `etb-scan` and nothing else. This distribution
contains no code.

It exists because `etb-scan` and `etbscan` are two separate names on PyPI,
while the import name and console script are both `etbscan`. Holding the
unhyphenated name keeps it from being squatted by someone else, since it is the
string most people will type.
